# E-Commerce Website

A simple and responsive mini e-commerce website built using **HTML, CSS, and JavaScript**.  
This project is **currently under development** and is being actively improved with new features and UI enhancements.

## Project Status
🚧 **Still Processing / In Progress**  
Some features are under development and may change as the project evolves.

## Features (Current)
- Clean dark-themed UI
- Product listing with fixed-size image cards
- Search products by name
- Filter products by category
- Add-to-cart functionality with cart count
- Responsive grid layout

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

## Project Structure
E-Commerce/
│── index.html
│── style.css
│── script.js
│── README.md


## How to Run
1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Browse products, use search and filters, and add items to cart

## Planned Features

- Cart page with price calculation
- LocalStorage-based cart persistence
- Improved mobile UI/UX
- Checkout flow (UI only)
